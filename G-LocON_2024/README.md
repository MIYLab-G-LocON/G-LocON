# G-LocON 2024

2024年度に作成されたG-LocONのベースコード（TechnicalSeminarで作成された改修前バージョン）をまとめたフォルダ．

## フォルダ構成

```
G-LocON_2024/
├── G-LocON_Client_2024/     G-LocON基盤クライアント（改修前・TechnicalSeminar版）
└── G-LocON_Server_2024/     G-LocON基盤サーバ（改修前・TechnicalSeminar版）
```

## 概要

| フォルダ | 内容 |
|---------|------|
| `G-LocON_Client_2024` | Google Maps SDKを使用したAndroidクライアント（2026年のosmdroid移行前のベースコード） |
| `G-LocON_Server_2024` | SignalingServer / STUNServer / VirtualClientで構成されるJavaサーバ（Eclipseプロジェクト形式） |

2026年に基盤の改修（osmdroid導入・Java17対応など）が行われた版は [`G-LocON_2026/`](../G-LocON_2026) を参照．
