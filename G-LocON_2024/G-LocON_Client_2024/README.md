# G-LocON Client 2024

2024年度，TechnicalSeminar（技術セミナー）で作成されたG-LocON Androidクライアントの改修前バージョン．

## 概要

- 地図表示: Google Maps SDK（`com.google.android.gms:play-services-maps`）
- 位置情報取得: `com.google.android.gms:play-services-location`
- Java 8 / compileSdk 34 / minSdk 26

2026年度の改修（[`G-LocON_2026/G-LocON_Client_2026`](../../G-LocON_2026/G-LocON_Client_2026)）で地図ライブラリはosmdroidに置き換えられている．改修前の実装を参照する際の資料として保存．

## 起動方法

Android Studioで `Test_GLocON/` を開き，通常通りビルド・実行する．
