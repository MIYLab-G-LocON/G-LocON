# G-LocON

**G-LocON（GPS-less Overlay COmmunication Network）** は，GPSに依存しないオーバレイ通信ネットワークを実現するP2P通信プラットフォームである．NATホールパンチングによりインフラ不要のUDP直接通信を確立し，モバイル端末間のリアルタイム位置情報共有を可能にする．

本リポジトリは，G-LocONを基盤とした研究成果を年度・研究者別に集約したものである．

## フォルダ命名規則

### 年度フォルダ

```
G-LocON_YYYY/
```

年度ごとにフォルダを作成する．

### 基盤フォルダ（任意）

```
G-LocON_Client_YYYY/
G-LocON_Server_YYYY/
```

G-LocON本体のクライアント・サーバをその年度に改修した場合のみ作成する．改修がなければ省略する．

### 研究者フォルダ

```
G-LocON_[学位][学年][教授イニシャル]_[氏名]/
```

| 記号 | 意味 | 選択肢 |
|------|------|--------|
| 学位 | 学士・修士・博士 | `B` / `M` / `D` |
| 学年 | 研究開始時の学年 | `1` `2` `3` `4` など |
| 教授イニシャル | 指導教員 | `M` / `Y` / `I` |
| 氏名 | 研究者の姓（ローマ字） | 例: `Kansaku` |

**例**

| フォルダ名 | 意味 |
|-----------|------|
| `G-LocON_M2M_Kansaku` | 修士2年・M教授・神作 |
| `G-LocON_B4Y_Yamada` | 学士4年・Y教授・山田 |
| `G-LocON_D1I_Suzuki` | 博士1年・I教授・鈴木 |
