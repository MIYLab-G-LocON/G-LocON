# G-LocON

**G-LocON（Geolocation Oriented Network）** は，位置情報に基づき近隣端末間でP2P（Peer-to-peer）ネットワークを構築するLBS（Location Based Service）の通信基盤として提案されたシステムである．ユーザの位置情報をサーバで管理し，この情報を用いて周辺に存在する端末間でP2Pネットワークを構築する．これにより，ユーザは近隣端末間で直接情報共有を行うことが可能となり，情報の取得にサーバへのアクセスが不要となる．さらに，近隣端末の発見や直接通信の性質から，アドホックネットワークへの応用も期待されており，車車間通信（V2V: Vehicle-to-vehicle）などネットワーク構築が不安定な環境下でも動的かつ効率的なネットワーク構築が可能である．

本リポジトリは，G-LocONを基盤とした研究成果を年度・研究者別に集約したものである．

## フォルダ命名規則

### 年度フォルダ

```
G-LocON_YYYY/
```

年度ごとにフォルダを作成する．

### 基盤フォルダ（任意）

```
G-LocON_Client_YYYY/
G-LocON_Server_YYYY/
```

G-LocON本体のクライアント・サーバをその年度に改修した場合のみ作成する．改修がなければ省略する．

### 研究者フォルダ

```
G-LocON_[学位][学年][教授イニシャル]_[氏名]/
```

| 記号 | 意味 | 選択肢 |
|------|------|--------|
| 学位 | 学士・修士・博士 | `B` / `M` / `D` |
| 学年 | 研究開始時の学年 | `1` `2` `3` `4` など |
| 教授イニシャル | 指導教員 | `M` / `Y` / `I` |
| 氏名 | 研究者の姓（ローマ字） | 例: `Kansaku` |

**例**

| フォルダ名 | 意味 |
|-----------|------|
| `G-LocON_M2M_Kansaku` | 修士2年・M教授・神作 |
| `G-LocON_B4Y_Yamada` | 学士4年・Y教授・山田 |
| `G-LocON_D1I_Suzuki` | 博士1年・I教授・鈴木 |

## 各年度の概要

### 2026年

| フォルダ | 内容 |
|---------|------|
| `G-LocON_Client_2026` | osmdroid導入・AsyncTask廃止・Java17対応など基盤を現代的に改修 |
| `G-LocON_Server_2026` | 同上（サーバ側） |
| `G-LocON_M2M_Kansaku` | G-LocONをV2V（車車間通信）に応用．交差点中心のETAベースP2Pグループ形成を実現 |

### 2024年

| フォルダ | 内容 |
|---------|------|
| `G-LocON_Client_2024` | 技術セミナーで作成された初期版クライアント（Google Maps SDK使用，2026年改修前のベースコード） |
| `G-LocON_Server_2024` | 同上（サーバ側，SignalingServer/STUNServer/VirtualClient構成） |

順次追加予定．
